## 🚀 Projeto em destaque

### Mo Drip

**Um marketplace de moda pensado para Angola.**

A Mo Drip é uma plataforma que aproxima vendedores de roupas, calçados e acessórios dos seus potenciais compradores, facilitando a descoberta de produtos e o contacto direto com as lojas.

**Funcionalidades principais:**
- Pesquisa e filtragem de produtos.
- Páginas dedicadas aos vendedores.
- Autenticação de utilizadores.
- Sistema de favoritos.
- Contacto direto com vendedores através do WhatsApp.
- Integração entre frontend, API e base de dados.

**Tecnologias:** React, TypeScript, Node.js, Express.js, PostgreSQL e Supabase.

🌐 **[Visitar a Mo Drip](https://modrip.store)**
