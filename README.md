## 🚀 Projeto em destaque

### 🛍️ Mo Drip — Marketplace de Moda

<a href="https://modrip.store">
  <img src="https://img.shields.io/badge/Visitar%20Mo%20Drip-modrip.store-000000?style=for-the-badge" alt="Visitar Mo Drip">
</a>

Marketplace desenvolvido para conectar vendedores de roupas, calçados e acessórios a potenciais compradores em Angola.

**Principais funcionalidades:**
- 🔎 Pesquisa e filtragem de produtos.
- 🏪 Páginas individuais para vendedores.
- 🔐 Autenticação de utilizadores.
- ❤️ Sistema de favoritos.
- 📱 Contacto direto com vendedores através do WhatsApp.
- 🔌 Integração entre frontend, API REST e base de dados.

**Tecnologias utilizadas:** React, TypeScript, Node.js, Express.js, PostgreSQL e Supabase.
